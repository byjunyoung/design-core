One engine, three doors

The same verbs, the same JSON, whichever door you come in by. That is why it fits a terminal, an agent and a browser without three products.

Screens by section, states as tabs, a drawer that knows the file and line, comments on elements, Apply / Reject on a proposal.
Under all three
src/verbs.js — one implementation per verb, returning plain JSON. The CLI prints it, the MCP server returns it, the viewer draws it. A rule added once is enforced everywhere at once.
