Three lanes. The person never drags anything; the agent never writes a file without a proposal; the tool never lets an undecided value reach main.

Where things live
The screen is a YAML file in your repo. The proposal is a file in .proposals/. The comment is a file in .comments/. Versions are git branches: working = branch, review = PR, canonical = main. Nothing is stored anywhere else.
