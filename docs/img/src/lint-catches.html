What lint catches — before anyone asks

Fifteen rules, each with a file, a YAML path and a line. Blocking stops handoff; warning is counted. On main, an undecided value is blocking.

L03 · required-states
The screen nobody drew
A list needs Empty, Loading and Error. A form needs Validation. Your team writes the table; lint enforces it.
L05 · flow-target
The arrow to nowhere
A typo in a screen name, a screen renamed without its flows — caught at the line, not at handoff.
L13 · layout-vocabulary
The pixel that escaped
Spacing is a token name or it is a failure. That is what keeps a design-system change from becoming a migration.
L08 · tbd
The value nobody decided
Counted per owner, blocking when overdue or on main. The to-do list writes itself.
L07 · patch-target
The state that patches a ghost
An Empty state that hides an element which no longer exists — the kind of drift a canvas never notices.
L15 · variant-shape
The variant that is really a state
An axis with one option, or an option named like a state, is asked about instead of quietly accepted.
